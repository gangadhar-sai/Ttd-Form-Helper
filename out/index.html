Architecture

Built to be trusted

TTD uses React event guards that block programmatic input. We bypass this cleanly without breaking site logic. Everything is local, static, and inspectable.

Main-world event bridge
Uses a bridge script in the page's MAIN world to simulate trusted, human-like events that React accepts.
Angular control injection
Injects values directly into the underlying Angular/Material form controls to ensure guaranteed change detection.
Zero-network footprint
Zero external libraries. CSP connect-src 'self' ensures the extension cannot talk to any server.
Pure Web Crypto
Encryption happens locally using the browser's native Web Crypto API. No external dependencies.

  3. 03Open your browser and navigate to chrome://extensions
  4. 04Enable Developer mode (toggle top-right).
  5. 05Click Load unpacked and select the folder you unzipped.
  6. 06Pin TTD Form Helper to your toolbar.

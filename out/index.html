What it does

Everything you need to beat the rush

01

One-click form fill

Save up to 6 pilgrims per group. Click Fill All and every name, age, Aadhaar, gender, and proof type populates across all rows simultaneously — typically in under 3 seconds.

02

Saved pilgrim roster

Build a master address book of family and friends. Add each person once with their full details, then pull them into any booking group with a single click. Never retype anyone twice.

03

Live Aadhaar validation

Every Aadhaar number is checked against India's real Verhoeff checksum algorithm as you type. A typo in any digit triggers an inline error before you ever reach the TTD site — saving you a rejected submission.

04

Floating quick-fill widget

A compact toolbar appears on every TTD page during rush hours. Hit Fill without opening the extension panel, and hit Continue to advance to the next step — all without alt-tabbing.

05

Multiple booking types

Five dedicated tabs cover Special Entry Darshan ₹300, Sri PAT, Srivari Seva registration, Srivani Darshan, and Senior Citizen / Differently Abled booking — each with its own layout and requirements.

06

Encrypted local vault

Optionally protect all saved data with a passphrase. Encryption uses AES-GCM-256 with PBKDF2 key derivation. The derived key lives only in browser memory and is wiped when you close the browser.

Privacy & security

Your Aadhaar never leaves your machine

Most extensions ask for broad permissions and phone home quietly. This one asks for almost nothing and cannot send data anywhere. Here's exactly how we prove it.

No network access
CSP connect-src 'self' blocks all outbound requests. Verified: zero entries in DevTools → Network while using the extension.
Minimal permissions
Only storage and sidePanel. No tabs, cookies, clipboard, or downloads. Cannot read your browsing history.
Site-restricted scripts
Content scripts load only on tirupatibalaji.ap.gov.in and ttdevasthanams.ap.gov.in. Inactive everywhere else.
Zero dependencies
No npm packages. No CDN links. No eval(). Every source file is readable in a plain-text editor.
AES-GCM vault encryption
Optional passphrase protection via PBKDF2-SHA256 (210k rounds). Derived key lives only in chrome.storage.session — memory, gone on browser close.
Exportable data
Backup your saved pilgrims to an encrypted JSON file. Import on another device. Full ownership, zero lock-in.

Installation

Get started in under two minutes

  1. 01Open your browser and navigate to chrome://extensions
  2. 02Enable Developer mode (toggle top-right)
  3. 03Click Load unpacked and select this folder: D:\TTD Form Helper - Copy
  4. 04Pin the extension to your toolbar for quick access
  5. 05Navigate to tirupatibalaji.ap.gov.in and click the icon

Works on Chrome, Edge, Brave, and Arc. Firefox has limited support (popup instead of side panel). Requires minimum Chrome 114.

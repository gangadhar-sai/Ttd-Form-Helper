Features

Everything you need for TTD bookings

Five dedicated tabs cover every booking type on the TTD portal, with smart validation and instant autofill.

🛕

Pilgrim Booking

Special Entry Darshan ₹300 & Sri PAT. Save up to 6 pilgrims per group, assign primary contact details (email, city, state, gothram), and fill the entire form in under 3 seconds with one tap.

🙏

Srivari Seva Registration

Complete volunteer form — personal details, fitness checkboxes, residential address, qualifications, languages, and references. Auto-attaches photo and ID proof via the HTML5 DataTransfer API.

👥

Seva Group Booking

Two-column layout with a team member sidebar. Quick-fill any member by number. One toggle copies the team leader's address to everyone instantly.

🪔

Srivani Darshan

Supports up to 9 pilgrims with one-click fill and a one-click copy from the main Pilgrim tab — perfect for family Srivani bookings.

👴

Senior Citizen / Differently Abled

Auto-detects seniors (65+) and their spouse from your booking list. Automatically attaches age-proof Aadhaar documents (PDF / PNG / JPEG ≤ 1 MB) to the upload field.

⚡

Floating Quick-Fill Widget

A floating toolbar appears on TTD pages during rush hours. Hit ⚡ TTD Fast Fill without opening the extension popup — fill details and proceed in one gesture.

🔐

AES-GCM Vault Encryption

Optional passphrase-protected encryption using PBKDF2-SHA256 (210 k iterations). Derived key lives only in browser memory — wiped when you close the browser. Zero server contact.

✅

Live Aadhaar Verhoeff Check

Every Aadhaar number is validated against the real 12-digit Verhoeff checksum algorithm as you type. Typos are caught before you even reach the TTD page.

🌐

6 Languages

Full UI translations in English, Hindi (हिन्दी), Kannada (ಕನ್ನಡ), Malayalam (മലയാളം), Tamil (தமிழ்), and Telugu (తెలుగు). Switch language on the fly from the popup settings.

Technology

Built with modern web standards

Zero dependencies. No external libraries. No telemetry. Everything runs in-browser.

Languages & APIs Used

JavaScript (ES2022) CSS 3 + CSS Variables Web Crypto API Chrome Extension API (MV3) chrome.storage.session chrome.sidePanel chrome.i18n HTML5 DataTransfer API PBKDF2-SHA256 AES-GCM-256 Verhoeff Checksum Algorithm Angular / Material DOM Injection

Key Engineering Highlights

  • page-bridge.js — Runs in the page's own MAIN world to bypass React's isTrusted event guard, letting us programmatically trigger onChange handlers exactly like a real user would.
  • autofill.js — Deep Angular/Material component injection walks up the DOM tree finding ngControl instances and calls setValue() directly, ensuring value parity with user input.
  • crypto.js — Pure Web Crypto. PBKDF2 key derivation, AES-GCM-256 encryption, base64 envelope wrapping. No npm packages, no CVE surface.
  • validation.js — Verhoeff checksum for Aadhaar, 10-digit mobile range checks, passport format rules, DOB-to-age cross-validation, PIN-code rules — all client-side before any network access.
Privacy & Security

Your data stays on your machine

This extension makes no network requests of any kind. Here's how we prove it.

🛡️

No network access at all

The Content Security Policy restricts connect-src to 'self'. The extension cannot fetch from or send data to any external server — not even analytics or crash reporting. Verified by opening DevTools → Network while using the extension: zero outbound requests.

🔒

Minimal Permissions

Only storage and sidePanel. No tabs, cookies, clipboard, or download permissions. Cannot read your browsing history.

🌐

Site-Restricted Access

Content scripts load only on tirupatibalaji.ap.gov.in and ttdevasthanams.ap.gov.in. Completely inactive on every other website.

📦

Zero Dependencies

No npm packages. No CDN links. No eval(). Every source file is readable in a plain-text editor. Supply-chain risk is impossible.

💾

Encrypted Backup Export

Export your saved data to a JSON file. Choose optional AES-256-GCM encryption with a passphrase before downloading.

Installation

Get started in 2 minutes

Works on Chrome, Edge, Brave, Arc, and any Chromium-based browser.

  1. Open your browser and navigate to chrome://extensions (or edge://extensions)
  2. Enable Developer mode using the toggle in the top-right corner
  3. Click Load unpacked and select this extension's folder
  4. Pin TTD Form Helper to your toolbar for quick access
  5. Navigate to https://tirupatibalaji.ap.gov.in and start filling forms!
⚠ Important: This is a development installation. For the published Chrome Web Store version, search "TTD Form Helper" once listed. The source here is the same code you'd get from the store.
